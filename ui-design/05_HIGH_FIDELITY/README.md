## 2. 窗口尺寸

| 尺寸 | 规则 | 原型中 |
|---|---|---|
| 1440×900（常用） | 完整工具标签、字标全文 | ✓ |
| 1024×768（常用小） | 工具只留图标 + 悬停提示（< 900 规则不触发，但工具文字本就为图标式；保存/复制保留 keycap） | ✓ |
| 640×420（最小） | 字标只留橙点；保存收为图标；属性条中间部分横向滚动，**删除 / 取消 / 确认固定在右侧**（评审中发现删除被挤出视野后修正）；状态栏隐藏 keycap | ✓ |

画布在任意尺寸默认“适应”；截图打开时若能 100% 完整放下则 100%（02 U02）。

## 3. 文案（中文，供实现直接使用）

| 位置 | 文案 |
|---|---|
| 空状态标题 | 开始一张截图 |
| 空状态入口 | 截图 / 打开图片 / 粘贴 |
| 拖放区 | 或把 PNG / JPEG 拖到这里 · 悬停：松开以打开 |
| 加载 | 正在打开… |
| 状态栏 | 已遮挡 N 处 |
| 复制成功 | 已复制到剪贴板 · 说明：宽 × 高 · 已遮挡 N 处 |
| 复制失败 | 复制失败：剪贴板被其他程序占用 · 重试 |
| 保存成功 | 已保存 · 文件名 · 打开文件夹 |
| 保存失败 | 保存失败：没有写入权限 · 换个位置 |
| 交付作废 | 内容已变化，请重新复制 |
| 导入失败 | 无法打开：格式不支持（仅 PNG / JPEG）／文件超过 25 MB／文件已损坏 |
| 截图失败 | 无法截图：系统拒绝访问屏幕 · 重试 |
| 关闭确认 | 有未复制或保存的编辑 · 关闭后这些编辑会丢失。· 取消 / 放弃编辑 / 复制后关闭 |
| 截图提示 | 拖拽选区 · 单击选窗口 · Enter 全屏 · Esc 取消 |
| 关于 | 图片只在本机处理，不上传、无账号、无遥测。 |

不出现“安全评分”“已脱敏”“绝对安全”之类承诺。

## 4. Slint 组件映射（06 实现依据）

| 设计组件 | Slint 组件（计划） | 备注 |
|---|---|---|
| 工具按钮 | `ToolButton`（`accessible-role: button`，内部 Text `accessible-role: none`） | 遮挡类带 `secure` 角标 |
| 主/次/危险按钮 | `ActionButton { kind }` | 内嵌 `Keycap` |
| 分段控件 | `Segmented { options, selected }` | |
| 色板 | `Swatches { colors, selected }` | 数字键 1–6 |
| 数值输入 | `NumberField`（`TextInput` + mono） | 回车提交到 Rust |
| 状态胶囊 | `StatePill { kind }` | 仅状态栏/Toast |
| Toast | 独立顶层窗口（无边框、置顶） | 复制成功后编辑窗口已关闭，Toast 必须独立 |
| 对话框 | `ConfirmDialog` 模态窗口 | Esc / Enter |
| 画布 | `Image`（Rust 合成预览）+ 叠加层（选中框/手柄/创建中轮廓） | 拖拽中只改叠加层 |
| 截图覆盖层 | 每显示器一个无边框全屏窗口 | 混合 DPI 风险最高，06 先做 |
| 托盘 | Slint `system-tray` 特性 | HYPOTHESIS，06 验证 |
| 关于 | `AboutDialog` 含 `AboutSlint` | 许可证条件 |
