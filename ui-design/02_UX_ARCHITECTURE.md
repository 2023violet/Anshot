## 1. 架构决策

| 编号 | 决策 | 放弃的方案与原因 |
|---|---|---|
| U01 | **单一编辑界面**：截图选区后直接打开编辑窗口，导入图片也进入同一窗口 | 在全屏覆盖层里就地编辑（Snipaste 式）：更快，但多显示器/混合 DPI 下要维护两套编辑界面，MVP 成本过高；保留为 P1 候选 |
| U02 | 编辑窗口打开时 **100% 显示，并尽量定位在原截图位置**，让用户感觉“原地编辑” | 总是居中适应窗口：会让截图看起来“跳走”和缩放 |
| U03 | **无侧栏**：顶部工具栏 + 随工具/选中对象出现的属性条 + 底部状态栏，画布占据其余空间 | 旧版右侧检查器：信息多、显得像调试工具，是“样机感”的来源之一 |
| U04 | **所见即所得，无“检查成品”步骤**；复制/保存总是交付当前版本 | 旧版独立复核步骤：用户认为繁琐；安全一致性由内部 Rust 不变量保证 |
| U05 | **后台常驻进程 + 托盘图标**进入 P0（只有“截图 / 打开图片 / 退出”三项菜单） | PRD 把托盘放在 P1，但全局快捷键需要常驻进程，因此最小托盘必须进 P0；设置页仍为 P1。**这是对 PRD 的修正，请在 Gate 02 一并确认** |
| U06 | 图层顺序固定：**原图 → 遮挡 → 标注**；遮挡永远直接作用于原图像素层 | 自由图层：标注可能被误认为“盖住了”隐私；固定顺序让“遮挡一定生效”可推理 |
| U07 | 复制后默认 **关闭编辑窗口并弹出提示**；保存后窗口保持 | 复制后保持窗口：多数分享场景复制即结束；P1 设置中可改 |

## 2. 界面清单（Surfaces）

| 编号 | 界面 | 何时出现 | 主要内容 |
|---|---|---|---|
| S0 | 托盘 | 常驻 | 菜单：截图、打开图片、退出；双击 = 截图 |
| S1 | 截图覆盖层 | 按快捷键 / 托盘截图 | 每个显示器一个冻结画面；选区框、尺寸标签、放大镜、窗口吸附高亮；操作提示 |
| S2 | 编辑窗口 | 选区完成 / 导入图片 | 顶部工具栏、属性条、画布、状态栏 |
| S3 | 启动空状态 | 从开始菜单直接启动且无图片时 | 三个入口：截图、打开文件、粘贴；拖放提示 |
| S4 | 轻提示（Toast） | 复制/保存成功或失败 | 屏幕右下角，3 秒消失；失败时带“重试” |
| S5 | 确认对话框 | 关闭/替换有未交付编辑 | “放弃编辑 / 复制后关闭 / 取消” |

## 3. 编辑窗口信息架构（S2）

```
┌──────────────────────────────────────────────────────────────┐
│ 工具栏  [选择 V][箭头 A][框 R][文字 T][序号 N][高亮 H] │ [遮挡 B][马赛克 M] │ [裁剪 C] ‖ [撤销][重做] ‖ [保存][复制 ▶] │
├──────────────────────────────────────────────────────────────┤
│ 属性条（随上下文）：颜色 ● ● ● ● ● ●  粗细 ─ ━ ▬  字号 ▾   │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                       画布（图片 + 对象）                     │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ 状态栏：1920×1080 · 已遮挡 2 处 · 100% [适应][1:1][−][+]     │
└──────────────────────────────────────────────────────────────┘
```

- 工具分三组：**标注**、**遮挡**（视觉上单独一组，用于强调安全语义）、**画布**（裁剪）。
- 主操作“复制”是唯一的强调按钮；“保存”为次要按钮。
- 属性条内容：标注工具 → 颜色/粗细（文字为字号）；遮挡工具 → 样式（实心/马赛克）；选中对象 → 该对象属性 + 删除；裁剪 → 尺寸数值 + 确认/取消；无工具上下文时隐藏，画布上移。
- 状态栏的“已遮挡 N 处”是唯一的隐私提示，不显示安全评分。
- 窗口最小尺寸 640×420；宽度 < 900 时工具栏标签隐藏只留图标，属性条可横向滚动。

## 4. 用户流程

### 4.1 截图分享（T1，主路径）
```
快捷键 → S1 冻结画面
  ├─ 拖拽 → 选区（可调整 8 向，Enter/双击确认）
  ├─ 单击 → 吸附窗口区域
  ├─ Enter（无选区）→ 当前显示器全屏
  └─ Esc / 右键 → 取消，无副作用
确认选区 → S2（100%，原位）→ 标注 / 遮挡 / 裁剪
  → Ctrl+C → 写入剪贴板 → 成功：关闭 S2 + S4「已复制」
                          失败：S2 保持 + S4「复制失败，重试」
  → Ctrl+S → 系统另存为 → 成功：S4「已保存 路径」，S2 保持
                          取消：无提示，无变化
                          失败：S4 原因 + 重试，编辑不丢
```

### 4.2 导入编辑（T2）
```
S3 / 托盘「打开图片」/ 拖入 S2 / 在 S2 中 Ctrl+V 粘贴图片
  → 解码中（窗口内进度，旧内容保留）
  → 成功：替换文档（若有未交付编辑先弹 S5）
  → 失败：S4 原因（格式不支持 / 文件过大 / 已损坏），旧文档不变
```

### 4.3 退出与保护
- 关闭 S2：有未交付编辑 → S5；已复制或已保存后无新改动 → 直接关闭。
- “未交付编辑” = 最后一次成功复制/保存之后有改动。
- 托盘退出时若有打开的 S2 且有未交付编辑 → 逐窗 S5。

### 4.4 失败与恢复总表
| 场景 | 表现 | 恢复 |
|---|---|---|
| 屏幕采集失败 | S4「无法截图：原因」 | 重试快捷键；不打开 S2 |
| 快捷键被占用 | 启动时 S4 提示 | 托盘截图可用；P1 设置中改键 |
| 导入失败 | S4 原因，旧文档保留 | 重新导入 |
| 复制失败 | S2 保持 + 重试 | 重试或改用保存 |
| 保存失败 | S4 原因 + 重试 | 换位置保存；不会生成半成品 |
| 交付期间又编辑 | 本次交付结果作废，提示“内容已变化，请重新复制” | 再复制 |

## 5. 操控模型

### 5.1 指针
| 操作 | 行为 |
|---|---|
| 在空白处拖拽（标注/遮挡工具） | 创建对象；Shift 约束（正方形 / 45° 箭头） |
| 单击对象（任何工具） | 选中；Shift+单击多选 |
| 拖拽选中对象 / 手柄 | 移动 / 八向调整；Alt 从中心调整 |
| 双击文字 | 进入文字编辑 |
| 滚轮 | 上下平移；Shift+滚轮左右；Ctrl+滚轮以指针为中心缩放 |
| 按住空格拖拽 / 中键拖拽 | 平移 |
| 右键对象 | 上下文菜单：删除、置顶/置底（同层内）、复制样式 |

### 5.2 键盘
| 键 | 功能 |
|---|---|
| V A R T N H B M C | 选择 / 箭头 / 框 / 文字 / 序号 / 高亮 / 遮挡 / 马赛克 / 裁剪 |
| 1–6 | 选择预设颜色 |
| Ctrl+Z / Ctrl+Y（Ctrl+Shift+Z） | 撤销 / 重做 |
| Delete / Backspace | 删除选中 |
| 方向键 / Shift+方向键 | 选中对象移动 1px / 10px |
| Tab / Shift+Tab | 在画布对象间切换选中 |
| Enter | 确认裁剪 / 确认选区；文字中换行用 Shift+Enter |
| Esc | 逐级退出：文字编辑 → 当前创建 → 取消选中 → 切回选择工具；**不关闭窗口** |
| Ctrl+C / Ctrl+S | 复制 / 另存 |
| Ctrl+0 / Ctrl+1 / Ctrl+= / Ctrl+- | 适应 / 100% / 放大 / 缩小 |
| Ctrl+W | 关闭（走 4.3 保护） |

- 文字编辑时，单键工具快捷键失效，避免输入中文时误切换（IME 组字期间所有快捷键暂停）。
- 无指针也能完成核心任务：键盘选工具 → 创建对象需指针（P1 增加“键盘创建：Enter 在视口中心放置默认大小对象，再用方向键调整”）。**P0 全键盘目标限定为：对已有对象选择、移动、调整、删除、撤销、复制、保存。**

### 5.3 裁剪
- C 进入裁剪：画布四周出现裁剪框和 8 个手柄，外部变暗；属性条显示宽×高数值可输入。
- Enter 确认 / Esc 取消；裁剪可撤销。裁剪框外的对象保留，但导出时被裁掉（再次放大裁剪框时恢复显示）。

## 6. 状态清单（供 05 高保真逐一设计）

| 界面 | 状态 |
|---|---|
| S1 | 冻结中（<200ms 目标）、悬停吸附、拖拽中、选区已定（可调整）、采集失败 |
| S2 画布 | 空（仅 S3 时）、加载中、编辑空闲、创建中、选中单个、选中多个、文字编辑、裁剪模式、大图缩放中 |
| S2 交付 | 复制中、复制成功（关闭）、复制失败、保存对话框、保存中、保存成功、保存失败、交付作废 |
| 控件 | 默认、悬停、按下、选中、焦点、禁用（例：无选中时删除禁用、无历史时撤销禁用） |

## 7. 可访问性基线
- 所有工具按钮有中文可读名称与快捷键提示（悬停 500ms 出提示）。
- 焦点可见；Tab 顺序：工具栏 → 属性条 → 画布 → 状态栏。
- 颜色不是唯一的状态区分：遮挡对象带斜线纹理边框，选中对象有手柄。
- Narrator 语义名称按框架能力在 Gate 03 spike 中验证（HYPOTHESIS）。

## 8. 与 Rust 架构的对应（HYPOTHESIS，06 细化）
- `shareready-editor` 扩展对象模型：`Redaction{Solid, SafeMosaic}`、`Annotation{Arrow, Rect, Text, Number, Highlight}`、`Crop`；全部进历史栈与版本令牌。
- `shareready-core` 新增：标注光栅化（含中文字形）、安全马赛克生成、裁剪导出。
- 新平台模块：屏幕采集（每显示器）、全局快捷键、托盘。
- GUI 只发送意图、只显示 Rust 合成结果。
