## 1. 架构决策

| 编号 | 决策 | 放弃的方案与原因 |
|---|---|---|
| U01 | **单一编辑界面**：截图选区后直接打开编辑窗口，导入图片也进入同一窗口 | 在全屏覆盖层里就地编辑（Snipaste 式）：更快，但多显示器/混合 DPI 下要维护两套编辑界面，MVP 成本过高；保留为 P1 候选 |
| U02 | 编辑窗口打开时 **100% 显示，并尽量定位在原截图位置**，让用户感觉“原地编辑” | 总是居中适应窗口：会让截图看起来“跳走”和缩放 |
| U03 | **无侧栏**：顶部工具栏 + 随工具/选中对象出现的属性条 + 底部状态栏，画布占据其余空间 | 旧版右侧检查器：信息多、显得像调试工具，是“样机感”的来源之一 |
| U04 | **所见即所得，无“检查成品”步骤**；复制/保存总是交付当前版本 | 旧版独立复核步骤：用户认为繁琐；安全一致性由内部 Rust 不变量保证 |
| U05 | **后台常驻进程 + 托盘图标**进入 P0（只有“截图 / 打开图片 / 退出”三项菜单） | PRD 把托盘放在 P1，但全局快捷键需要常驻进程，因此最小托盘必须进 P0；设置页仍为 P1。**这是对 PRD 的修正，请在 Gate 02 一并确认** |
| U06 | 图层顺序固定：**原图 → 遮挡 → 标注**；遮挡永远直接作用于原图像素层 | 自由图层：标注可能被误认为“盖住了”隐私；固定顺序让“遮挡一定生效”可推理 |
| U07 | 复制后默认 **关闭编辑窗口并弹出提示**；保存后窗口保持 | 复制后保持窗口：多数分享场景复制即结束；P1 设置中可改 |

## 2. 界面清单（Surfaces）

| 编号 | 界面 | 何时出现 | 主要内容 |
|---|---|---|---|
| S0 | 托盘 | 常驻 | 菜单：截图、打开图片、退出；双击 = 截图 |
| S1 | 截图覆盖层 | 按快捷键 / 托盘截图 | 每个显示器一个冻结画面；选区框、尺寸标签、放大镜、窗口吸附高亮；操作提示 |
| S2 | 编辑窗口 | 选区完成 / 导入图片 | 顶部工具栏、属性条、画布、状态栏 |
| S3 | 启动空状态 | 从开始菜单直接启动且无图片时 | 三个入口：截图、打开文件、粘贴；拖放提示 |
| S4 | 轻提示（Toast） | 复制/保存成功或失败 | 屏幕右下角，3 秒消失；失败时带“重试” |
| S5 | 确认对话框 | 关闭/替换有未交付编辑 | “放弃编辑 / 复制后关闭 / 取消” |

## 3. 编辑窗口信息架构（S2）

```
┌──────────────────────────────────────────────────────────────┐
│ 工具栏  [选择 V][箭头 A][框 R][文字 T][序号 N][高亮 H] │ [遮挡 B][马赛克 M] │ [裁剪 C] ‖ [撤销][重做] ‖ [保存][复制 ▶] │
├──────────────────────────────────────────────────────────────┤
│ 属性条（随上下文）：颜色 ● ● ● ● ● ●  粗细 ─ ━ ▬  字号 ▾   │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                       画布（图片 + 对象）                     │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ 状态栏：1920×1080 · 已遮挡 2 处 · 100% [适应][1:1][−][+]     │
└──────────────────────────────────────────────────────────────┘
```

- 工具分三组：**标注**、**遮挡**（视觉上单独一组，用于强调安全语义）、**画布**（裁剪）。
- 主操作“复制”是唯一的强调按钮；“保存”为次要按钮。
- 属性条内容：标注工具 → 颜色/粗细（文字为字号）；遮挡工具 → 样式（实心/马赛克）；选中对象 → 该对象属性 + 删除；裁剪 → 尺寸数值 + 确认/取消；无工具上下文时隐藏，画布上移。
- 状态栏的“已遮挡 N 处”是唯一的隐私提示，不显示安全评分。
- 窗口最小尺寸 640×420；宽度 < 900 时工具栏标签隐藏只留图标，属性条可横向滚动。

## 4. 用户流程

### 4.1 截图分享（T1，主路径）
```
快捷键 → S1 冻结画面
  ├─ 拖拽 → 选区（可调整 8 向，Enter/双击确认）
  ├─ 单击 → 吸附窗口区域
  ├─ Enter（无选区）→ 当前显示器全屏
  └─ Esc / 右键 → 取消，无副作用
确认选区 → S2（100%，原位）→ 标注 / 遮挡 / 裁剪
  → Ctrl+C → 写入剪贴板 → 成功：关闭 S2 + S4「已复制」
                          失败：S2 保持 + S4「复制失败，重试」
  → Ctrl+S → 系统另存为 → 成功：S4「已保存 路径」，S2 保持
                          取消：无提示，无变化
                          失败：S4 原因 + 重试，编辑不丢
```

### 4.2 导入编辑（T2）
```
S3 / 托盘「打开图片」/ 拖入 S2 / 在 S2 中 Ctrl+V 粘贴图片
  → 解码中（窗口内进度，旧内容保留）
  → 成功：替换文档（若有未交付编辑先弹 S5）
  → 失败：S4 原因（格式不支持 / 文件过大 / 已损坏），旧文档不变
```

### 4.3 退出与保护
- 关闭 S2：有未交付编辑 → S5；已复制或已保存后无新改动 → 直接关闭。
- “未交付编辑” = 最后一次成功复制/保存之后有改动。
- 托盘退出时若有打开的 S2 且有未交付编辑 → 逐窗 S5。

### 4.4 失败与恢复总表
| 场景 | 表现 | 恢复 |
|---|---|---|
| 屏幕采集失败 | S4「无法截图：原因」 | 重试快捷键；不打开 S2 |
| 快捷键被占用 | 启动时 S4 提示 | 托盘截图可用；P1 设置中改键 |
| 导入失败 | S4 原因，旧文档保留 | 重新导入 |
| 复制失败 | S2 保持 + 重试 | 重试或改用保存 |
| 保存失败 | S4 原因 + 重试 | 换位置保存；不会生成半成品 |
| 交付期间又编辑 | 本次交付结果作废，提示“内容已变化，请重新复制” | 再复制 |

## 5. 操控模型

### 5.1 指针
| 操作 | 行为 |
|---|---|
| 在空白处拖拽（标注/遮挡工具） | 创建对象；Shift 约束（正方形 / 45° 箭头） |
| 单击对象（任何工具） | 选中；Shift+单击多选 |
| 拖拽选中对象 / 手柄 | 移动 / 八向调整；Alt 从中心调整 |
| 双击文字 | 进入文字编辑 |
| 滚轮 | 上下平移；Shift+滚轮左右；Ctrl+滚轮以指针为中心缩放 |
| 按住空格拖拽 / 中键拖拽 | 平移 |
| 右键对象 | 上下文菜单：删除、置顶/置底（同层内）、复制样式 |

### 5.2 键盘
| 键 | 功能 |
|---|---|
| V A R T N H B M C | 选择 / 箭头 / 框 / 文字 / 序号 / 高亮 / 遮挡 / 马赛克 / 裁剪 |
| 1–6 | 选择预设颜色 |
| Ctrl+Z / Ctrl+Y（Ctrl+Shift+Z） | 撤销 / 重做 |
| Delete / Backspace | 删除选中 |
| 方向键 / Shift+方向键 | 选中对象移动 1px / 10px |
| Tab / Shift+Tab | 在画布对象间切换选中 |
| Enter | 确认裁剪 / 确认选区；文字中换行用 Shift+Enter |
| Esc | 逐级退出：文字编辑 → 当前创建 → 取消选中 → 切回选择工具；**不关闭窗口** |
| Ctrl+C / Ctrl+S | 复制 / 另存 |
| Ctrl+0 / Ctrl+1 / Ctrl+= / Ctrl+- | 适应 / 100% / 放大 / 缩小 |
| Ctrl+W | 关闭（走 4.3 保护） |

- 文字编辑时，单键工具快捷键失效，避免输入中文时误切换（IME 组字期间所有快捷键暂停）。
- 无指针也能完成核心任务：键盘选工具 → 创建对象需指针（P1 增加“键盘创建：Enter 在视口中心放置默认大小对象，再用方向键调整”）。**P0 全键盘目标限定为：对已有对象选择、移动、调整、删除、撤销、复制、保存。**

### 5.3 裁剪
- C 进入裁剪：画布四周出现裁剪框和 8 个手柄，外部变暗；属性条显示宽×高数值可输入。
- Enter 确认 / Esc 取消；裁剪可撤销。裁剪框外的对象保留，但导出时被裁掉（再次放大裁剪框时恢复显示）。

## 6. 状态清单（供 05 高保真逐一设计）

| 界面 | 状态 |
|---|---|
| S1 | 冻结中（<200ms 目标）、悬停吸附、拖拽中、选区已定（可调整）、采集失败 |
| S2 画布 | 空（仅 S3 时）、加载中、编辑空闲、创建中、选中单个、选中多个、文字编辑、裁剪模式、大图缩放中 |
| S2 交付 | 复制中、复制成功（关闭）、复制失败、保存对话框、保存中、保存成功、保存失败、交付作废 |
| 控件 | 默认、悬停、按下、选中、焦点、禁用（例：无选中时删除禁用、无历史时撤销禁用） |

## 7. 可访问性基线
- 所有工具按钮有中文可读名称与快捷键提示（悬停 500ms 出提示）。
- 焦点可见；Tab 顺序：工具栏 → 属性条 → 画布 → 状态栏。
- 颜色不是唯一的状态区分：遮挡对象带斜线纹理边框，选中对象有手柄。
- Narrator 语义名称按框架能力在 Gate 03 spike 中验证（HYPOTHESIS）。

## 8. 与 Rust 架构的对应（HYPOTHESIS，06 细化）
- `shareready-editor` 扩展对象模型：`Redaction{Solid, SafeMosaic}`、`Annotation{Arrow, Rect, Text, Number, Highlight}`、`Crop`；全部进历史栈与版本令牌。
- `shareready-core` 新增：标注光栅化（含中文字形）、安全马赛克生成、裁剪导出。
- 新平台模块：屏幕采集（每显示器）、全局快捷键、托盘。
- GUI 只发送意图、只显示 Rust 合成结果。

## v0.2 增补流程（2026-10-21）

- **S1 截图层 → 选区工具条**：有选区且未按住鼠标时，在选区下方（放不下则上方 / 内侧）显示：取消 Esc · 编辑 Enter · 保存 Ctrl+S · 钉图 Ctrl+T · 长截图 · 复制 Ctrl+C。复制在编辑窗隐藏的情况下走完整 Rust 交付路径，成功后系统提示；失败或被拒时打开编辑窗显示原因。
- **长截图**：截图层关闭 → 控制条出现在选区旁（不覆盖选区；无处可放则拒绝并提示）→ 用户滚动目标窗口 → 控制条显示“已拼接 N 像素高”，滚太快显示“没接上——请往回滚一点”，到上限显示“已到长度上限” → 完成进入编辑器 / 取消恢复原状。
- **钉图**：来自选区（原位）、编辑器（Ctrl+T，渲染后的成品）或历史项；拖动、滚轮缩放、右键菜单（复制 / 另存为 / 在编辑器中打开 / 不透明度 / 关闭）、Esc 或双击关闭。钉图的复制与保存不进入历史。
- **截图历史**：Ctrl+H、工具栏、托盘、空状态入口；缩略图网格（后台解码），每项打开 / 复制 / 钉图 / 删除，全部清空；空状态说明“复制或保存后会出现在这里”。
- **自定义颜色**：属性栏“自定义…” → 饱和度 / 亮度方块 + 色相条 + HEX + 最近使用 → Enter 使用 / Esc 取消；第 7 个色块（键 7）为当前自定义色。
- **形状对**：工具栏“框 / 椭圆（R/E）”“箭头 / 直线（A/L）”共用按钮，属性栏切换形状并转换选中对象；画笔（P）独立按钮。

## v0.3 增补流程（2026-10-27，代理起草；代理按用户 2026-10-27 的委托（“自行执行，直到新版本的发布”）确认，用户未逐项审阅）

- **延时截图**：托盘“延时 N 秒截图”或 `--delayed-capture` → 屏幕角落倒计时窗（不进入任何截图）→ 归零后进入截图层。倒计时中 Esc 或再次截图取消倒计时；倒计时窗不抢焦点。秒数在设置“常规”里选 3 / 5 / 10。
- **截图层辅助**：
  - R 重复上次区域（只在内存中，重启后没有；没有上次区域时按钮不可用）；
  - 选区工具条“尺寸” → 面板（1:1 / 4:3 / 16:9 与精确宽 × 高，回车生效）；超出所在显示器时缩小到显示器内，不跨屏；
  - Shift 拖动锁定正方形，调整手柄时锁定当前比例；
  - 放大镜显示坐标与 #RRGGBB，Shift+C 复制颜色并提示“已复制颜色”。
- **识别文字**：入口为选区工具条“识别文字”、编辑器 Ctrl+Shift+O / 工具栏、钉图右键。→ 识别窗（识别中…）→ 结果可编辑，“复制全部”，Esc 关闭。失败：没有可用的识别语言时说明如何在 Windows 设置里添加；识别失败给出人话提示。同一时间只运行一个识别任务。编辑器里识别的是导出图（遮挡后的样子）。
- **隐私辅助**（设置 → 隐私）：遮挡外扩 4 px、未遮挡提醒（复制 / 保存后状态栏警告，不拦截）、复制不进剪贴板历史与云同步、历史保留天数、退出时清空。
- **标注**：聚光灯 S（框外压暗，点框边选中）、放大镜标注 Z（拖出源区域，旁边自动放 2 倍放大框）；选中编号 / 图形 / 文字时 Alt+滚轮调整编号、线宽或字号。
- **语言**：设置 → 常规 → 语言（跟随系统 / 中文 / English），立即生效。

## v0.4 增补流程（2026-11-01，代理起草；用户 2026-11-02 确认）

- **手动检查**：工具栏“分享前检查”或 Ctrl+Shift+K → 面板“正在检查…” → 列表（类别、首尾几个字符，默认全选）与画布上的建议框 → 取消个别项 → 选“打码”或“替换成占位文字” → “遮挡所选（N）”。一次应用只占一步撤销。没有发现时写“没有发现可疑内容”。关闭或 Esc 不改图。
- **自动检查**：复制 / 保存成功后在后台读刚交付的图，不拦截。发现新内容时提示“已复制 · 发现 N 处…”，带“查看”。编辑器已隐藏时用系统提示窗，点“查看”重新打开编辑器。此时面板写明剪贴板里还是刚才那张图，按钮是“遮挡并重新复制（N）”；保存路径提示再保存一次。
- **不重复打扰**：用户看过且没勾选的位置不再提示；撤销遮挡后会再次提示。
- **同词全遮**：选中一个遮挡 → 属性栏“遮住相同内容” → 同一个列表确认。没找到或框内没字时给出提示。新遮挡沿用所选遮挡的样式和替换文字。
- **替换**：选中一个遮挡 → “替换为文字” → 输入 → 回车；Esc 取消。
- **出图自检**：有遮挡时，交付后的检查还会核对遮挡框里的文字。读不出时提示“已核对 N 处遮挡：成品里识别不出”；还能读出（比如另一处同名没遮）时那个位置进入列表。
- **失败**：缺 OCR 语言时，按钮说明如何安装，自动检查保持安静；识别失败提示“无法检查”，不会显示成“没有发现”。
- **设置**：隐私页“分享前检查”：复制和保存后检查 / 只手动检查。

## v0.5 增补流程（2026-11-02，代理起草；用户 2026-11-02 确认）

- **进入**：工具栏“美化”或 Ctrl+Shift+B → 面板打开，画布切换为“成品预览”（Rust 渲染的带框成品）。与检查面板互斥：打开一个会关掉另一个。
- **调整**：开关；背景（8 组预设 + 自动取色）；留白、圆角、阴影（无 / 小 / 中 / 大）；比例（自由 / 1:1 / 4:3 / 16:9 / 3:4 / 9:16）；外框（无 / macOS / Windows / 浏览器）和外框文字。每次改动只重绘预览，不进撤销。
- **预览时**：标注工具暂停，工具快捷键不生效；复制 / 保存照常，交付的是带框成品。
- **完成**：关闭面板或 Esc 回到编辑；美化设置保留在当前文档，状态栏显示成品尺寸。
- **超限**：成品会超过 2400 万像素时先缩小留白；仍放不下时提示“图片太大，无法美化”并关掉开关，复制 / 保存仍可用（不带框）。
- **恢复**：关掉开关即恢复原样；撤销 / 重做不影响美化。
- **新截图**：默认不美化；设置“常规 → 新截图默认美化”打开后，新文档沿用上次样式（不含外框文字）。
- **检查**：交付后的自动检查只看成品里的截图区域；外框文字和背景不报。

## v0.6 增补流程（2026-11-06，代理起草；**代理按用户 2026-11-06 的目标授权确认（“依照 plan 指定的方案计划逐步执行，直到新版本完成构建与发布……我们不参与决策”），用户未逐项审阅**）
- **收集（三个入口）：** 选区工具条“加入步骤”或 Ctrl+J（原始截图直接放进步骤栏，不开编辑器，标“未编辑”）；编辑器 Ctrl+J 或步骤栏“加入当前图”（放进去的是画好遮挡和标注的结果，不带美化）；截图历史每项“加入步骤”、步骤栏“从文件加入”。每次加入提示“已加入第 N 步 · 共 N 步”。
- **整理：** 工具栏“步骤图”或 Ctrl+Shift+J 打开步骤栏（与检查、美化面板互斥）。每一步：缩略图、序号、说明输入框、上移 / 下移 / 编辑 / 删除。删除后提示带“撤销”（恢复最近删除的一步）。
- **排版：** 排列（纵向 / 横向 / 网格）、间距（小 / 中 / 大）、编号（开 / 关）、说明（开 / 关）、统一宽度（开 / 关）、背景（白 / 浅 / 深）。画布显示拼合预览，标注工具暂停。
- **拼合：** “拼合并编辑” → 新文档“步骤图 N 步.png”进入编辑器；当前文档有未交付编辑时走现有“替换”对话框。步骤仍保留，可回步骤栏调整后重新拼合。
- **编辑某一步：** 把这一步作为文档打开，顶部横幅“正在编辑第 N 步”，Ctrl+J / 按钮变为“更新第 N 步”；换成别的文档即解除关联。
- **连拍：** 步骤栏或托盘菜单打开“连拍”。打开后截图选好区域按回车（或双击）直接加入步骤，不弹编辑器；工具条其他操作照常。托盘菜单显示“步骤图（N）”。关闭连拍时打开编辑器并显示步骤栏。
- **失败与恢复：** 第 21 步 → “最多 20 步”，不加入；拼合超过 2400 万像素且缩到下限仍放不下 → “图片太大，无法拼合”，步骤不变；文件无法读取 → 沿用打开失败提示；退出程序 → 步骤清空（不落盘，无需确认，步骤栏有步骤时退出确认里说明）。
