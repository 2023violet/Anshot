## 发现（按优先级）
| 编号 | 级别 | 现象（亲测或代码确认） | 建议 |
|---|---|---|---|
| R1 | 中 | 编辑窗打开时按截图快捷键，**编辑窗本身被冻结进截图**，挡住要截的内容（亲测） | 冻结前先隐藏编辑窗，取消后恢复 |
| R2 | 中 | 打开损坏文件时提示原始调试文本：`文件已损坏（CoreFailure("invalid image header: … ChunkType { … }")）`；不存在的文件显示 `(os error 3)`（亲测） | 映射为人话（“不是有效的 PNG/JPEG 图片”“找不到文件”），细节不上屏 |
| R3 | 中 | 工具栏只有图标，**悬停无提示**，新用户不知道 A/R/T/N/H/B/M/C 是什么（亲测悬停 1.5 秒无反应；只有读屏能读到名称） | 悬停提示“箭头 A”等 |
| R4 | 中 | PRD §7 承诺的 **Shift 约束**未实现（框不能锁正方形、箭头不能锁 45°）（代码确认） | 按住 Shift 约束形状 |
| R5 | 中 | 无开机自启：重启电脑后不手动打开就没有截图快捷键（代码确认） | 设置页加“开机启动”（默认关，只写当前用户启动项） |
| R6 | 低 | 截图选区和裁剪框画完后不能拖边调整，只能重画（亲测提示“重新拖拽可改选区”） | 选区 / 裁剪框加八向手柄 |
| R7 | 低 | 刚打开截图层时放大镜停在上次指针位置，移动鼠标后才更新（亲测，真实使用影响小） | 打开时以当前指针初始化 |

已确认**没有问题**：最小窗口 640×420 由系统拖拽强制，最小尺寸下主按钮“复制”“保存”仍可见；有未交付编辑时导入新图会弹替换确认；截图后默认选中遮挡工具，符合“先遮挡再分享”的主任务。
