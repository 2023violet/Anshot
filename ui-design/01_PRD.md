# 01 PRD — ShareReady（临时代号）

版本 v0.1 草稿　日期 2026-10-19　状态：**待 Gate 01 确认**
输入：[01_PRD_INPUTS.md](01_PRD_INPUTS.md)　基线：`main`，tag `pre-redesign-2026-10-19`

## 1. 一句话定义

一款 Windows 桌面截图工具：按下快捷键截图，加上箭头和文字说明，遮住不该公开的信息，一键复制或保存。**所有像素处理和导出都由 Rust 完成，遮挡区域保证不含任何原图信息。**

## 2. 目标用户

| 用户 | 典型场景 | 现在怎么做 / 痛点 |
|---|---|---|
| 日常分享者（主） | 把聊天、订单、账号页截图发给客服、朋友、群 | 系统截图后用画图乱涂，或打马赛克——马赛克和模糊可能被还原，元数据也可能残留 |
| 技术/办公用户 | 写工单、Bug 报告、操作文档，需要箭头、编号、框选并遮掉 token、邮箱、内网地址 | ShareX 功能多但复杂；Snipaste 标注好用但遮挡不强调安全 |
| 作品集评审者（次） | 看项目代码与设计 | 关注 Rust 可信架构与产品完成度 |

## 3. 产品价值与定位

- **快**：快捷键 → 选区 → 标注/遮挡 → 复制，熟练用户 10 秒内完成。
- **可信**：遮挡是“替换”而不是“涂抹”；导出的是全新 PNG，不带原图元数据；画布显示什么，导出就是什么。
- **好用、好看**：现代、克制、操控顺手，像成熟产品，不像样机。

竞品对照（DOCUMENTED，未做实测对比）：ShareX（功能全、复杂）、Snipaste（截图标注体验好，遮挡非安全语义）、Windows 截图工具（简单、标注少）、Redacted 等（专注脱敏，缺截图采集）。本产品的差异点是“截图标注流畅度 + 遮挡安全语义”的组合，**是否优于竞品为 HYPOTHESIS**。

## 4. 核心端到端任务

**T1 截图分享（主任务）**
1. 按全局快捷键（默认 `Ctrl+Shift+A`，可改）→ 屏幕冻结，进入选区。
2. 拖出区域（或单击选窗口 / 回车全屏），松手进入编辑。
3. 用箭头、矩形、文字、序号标注；用遮挡工具框住手机号等信息。
4. `Ctrl+C` 复制到剪贴板（或 `Ctrl+S` 另存 PNG），窗口关闭，提示“已复制”。
5. 粘贴到微信/飞书/浏览器，看到的与画布完全一致。

**T2 编辑已有图片**：拖入或粘贴图片 / 打开文件 → 同 3–5。

**失败与恢复**：截图权限/采集失败给出原因并可重试；复制或保存失败不关闭窗口、不丢编辑；关闭有未交付编辑时询问。

## 5. 功能范围

### P0（MVP 必须）
| 编号 | 能力 | 说明 |
|---|---|---|
| F01 | 全局快捷键截图 | 区域选取、窗口吸附、全屏；多显示器；选区放大镜与像素尺寸提示 |
| F02 | 导入图片 | 打开文件、拖放、剪贴板粘贴（PNG/JPEG，EXIF 方向归一） |
| F03 | 标注 | 箭头、矩形框、文字（中文）、自动递增序号、高亮笔；颜色 6 色预设 + 粗细 3 档 |
| F04 | 遮挡 | **实心块**、**安全马赛克**（见 §6）；可移动、八向调整、删除 |
| F05 | 选择与编辑 | 选中、移动、调整、删除、撤销/重做（不限步数，单次会话内） |
| F06 | 裁剪 | 编辑中调整画布范围；导出按裁剪结果 |
| F07 | 交付 | 复制到剪贴板、另存为新 PNG（不覆盖源文件）；结果如实提示 |
| F08 | 视图 | 适应窗口、100%、缩放、平移；高 DPI 正确 |
| F09 | 键盘 | 工具切换单键（V/A/R/T/N/M/C…）、核心流程可全键盘完成 |

### P1（MVP 后）
钉图到桌面、历史截图列表、导出尺寸缩放、自定义颜色、贴图/图片叠加、长截图、托盘常驻与设置页、浅/深主题切换。

### 非目标（本轮明确不做）
OCR 与自动隐私识别、云端上传与分享链接、账号、录屏/GIF、批量处理、PDF、插件系统、跨平台（macOS/Linux）、对原图像素的模糊/像素化（见 §6）。

## 6. Rust 可信边界与遮挡安全语义

**可信路径（必须在 Rust 内完成）**：屏幕采集得到的像素、文件/剪贴板解码、标注与遮挡合成、裁剪、PNG 编码、剪贴板写入与文件保存。UI 层也是 Rust 原生，不嵌入 WebView/JS。

**遮挡语义**
- 实心块：区域像素被纯色替换。
- 安全马赛克：外观像马赛克，但色块由**与原图无关的生成图案**（固定调色或随机种子）填充，区域内不含原像素信息；视觉上比黑块柔和。
- 不提供基于原像素的模糊/像素化作为“遮挡”——这类效果可被部分还原。若将来作为装饰功能提供，必须标注“非安全”并与遮挡工具分开（P2 以后）。

**一致性不变量**
- 画布显示由与导出相同的 Rust 合成结果驱动；复制/保存的始终是当前编辑版本，旧版本结果被拒绝（沿用现有 Editor 版本令牌）。
- 导出 PNG 为新图，不带 EXIF/文本块等源元数据。
- 旧方案的“检查成品”独立步骤取消——改为所见即所得，安全性由内部不变量保证（回应“流程繁琐”）。

**复用与新增**
- 复用：`shareready-core`（解码、方向、实心替换、PNG）、`shareready-editor`（文档、选择、八向、历史、版本令牌）、`shareready-platform-windows`（有界读取、DIB、保存）。
- 新增模块（HYPOTHESIS，在 02/03 细化）：屏幕采集与选区覆盖层、标注对象模型与 Rust 光栅化（含中文文字渲染）、安全马赛克生成、裁剪、全局快捷键。
- 现有 5 张冻结金样本继续通过；新功能各自新增金样本。

## 7. 体验原则（来自对旧版的反面约束）

| 旧问题 | 新原则 |
|---|---|
| 视觉丑/过时 | 现代克制的视觉，画布为主角；03 阶段比较 2–3 个方向再定 |
| 操控别扭 | 对齐主流截图工具习惯（Snipaste/Figma 式）：拖拽即画、单键切工具、Shift 约束、滚轮缩放、空格平移 |
| 流程繁琐 | 最短路径：截图 → 标 → 复制，最少 3 步；无强制确认步骤 |
| 像样机不像产品 | 完整状态（空、加载、错误、成功）、一致组件、流畅动效、细节对齐 |

## 8. 约束

- 平台：Windows 10/11，x64；单一可执行文件，无需安装 .NET/WebView2。
- 语言：界面中文优先。
- 本地运行：无网络请求、无遥测、无账号。
- 性能目标（HYPOTHESIS，07 实测）：快捷键到选区出现 < 200ms；24MP 图编辑流畅；复制 < 1s。
- 依赖精简、锁定；GUI 框架在 Gate 03 决定。

## 10. 风险与待定问题

- **屏幕采集覆盖层**：全屏冻结、多显示器混合 DPI 下的覆盖窗口是 Rust GUI 的难点，Gate 03 spike 必须覆盖。
- **中文文字标注渲染**：需在 Rust 内光栅化，字体与排版质量待验证。
- **框架选型**：egui 即时模式适合画布，iced/Slint 组件与视觉更规整——由 spike 决定。
- 待你确认：默认快捷键；是否 P0 需要托盘常驻（当前放 P1）；安全马赛克的外观是否可接受。
