## 1. 候选方向（同一主工作台、同一任务对比）

| | A · Raycast 式 | B · Linear 式 | C · Figma 式 |
|---|---|---|---|
| 气质 | 深色桌面效率工具，快捷键优先，像随叫随到的系统组件 | 深色、精密、克制，单一品牌强调色 | 白底黑字的编辑器，柔和色块，胶囊按钮 |
| 与产品契合 | **高**：同为“快捷键唤起 → 做完即走”的桌面工具；keycap 快捷键提示直接服务“操控顺手” | **高**：单一强调色适合选中、焦点、手柄 | 中：画布工具惯例好，但色块和胶囊是营销页语言，放在工具栏里显得幼稚 |
| 画布内容辨识 | 中性深色框让截图内容（多为浅色）成为视觉中心 | 同左 | 白底与浅色截图边界弱，需要额外描边 |
| 信息密度 | 紧凑（6–10px 圆角、16–24px 内距） | 紧凑 | 宽松 |
| 原生实现成本 | 低：无阴影、无渐变，只靠表面色阶 + 1px 发丝线 | 低 | 中：大量胶囊与色块 |
| 风险 | 白色主按钮在深色界面里较突兀，需要节制 | 只有一种强调色，标注颜色需另外定义 | 与“像成熟工具”的目标冲突 |

## 2. 结论：融合 A 为主 + B 的强调色规则

**名称：「暗夜工作台」（Raycast 骨架 + Linear 强调色）**

- **从 Raycast 取**：深色表面色阶（无阴影，靠亮度分层）、1px 发丝线、6/8/10px 圆角体系、keycap 快捷键样式、白色主按钮只给唯一主操作“复制”、“饱和色只出现在内容里，不出现在界面框架上”。
- **从 Linear 取**：唯一的品牌强调色 lavender-blue `#5e6ad2`，只用于选中、焦点环、当前工具、对象手柄；不做装饰、不做底色。
- **从 Figma 取（只取原则，不取外观）**：工具框架保持单色，让内容颜色说话；属性条随上下文出现。
- **放弃**：Raycast 的红色条纹 hero、营销尺寸字号；Linear 的极端负字距；Figma 的胶囊按钮与粉彩色块。

## 3. 本产品特有的决定

1. **标注色是“内容色”**，不是界面色：6 色预设（红、橙、黄、绿、蓝、白/黑）饱和、高辨识度，与界面强调色分开定义。这正好对应 Raycast“饱和色只在内容里”的规则。
2. **遮挡工具要有“安全”视觉身份**：遮挡组按钮使用盾牌图标 + 专用中性蓝灰 `#7a7fad`（取自 Linear `brand-secure`）作为选中底色，与标注工具的选中态区分。
3. **MVP 只做深色主题**；浅色主题为 P1（PRD 已列入），04 的 Token 按语义命名，便于以后加第二套。
4. **中文字体**：Inter 只覆盖拉丁字符，中文使用仓库已带的 Noto Sans CJK SC（OFL）；Raycast 的 `ss03` 字形特性在原生框架中可能不支持，列为可选（HYPOTHESIS）。
