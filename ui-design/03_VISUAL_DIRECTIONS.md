## 1. 候选方向（同一主工作台、同一任务对比）

| | A · Raycast+Linear 暗夜工作台（v0.1） | B · Cursor 暖奶油编辑风 | C · NVIDIA 工业取景框 | D · Sentry 午夜紫+青柠 |
|---|---|---|---|---|
| 气质 | 深色、克制、专业 | 浅色暖调、杂志感、安静自信 | 纯黑 + 极饱和信号色，锐角 | 深紫、顽皮、反叛 |
| 个性 / 品牌感 | 低：与大量深色工具相似 | **中高**：浅色工具少见暖奶油底，辨识度来自“温度”而非装饰 | 高，但偏硬朗冷峻 | 最高，但容易幼稚 |
| 截图内容辨识 | 好 | 好：白色截图在奶油底上有自然边界 | 好 | 紫底会染色感知 |
| 长时间操作 | 好 | 好 | 刺眼信号色易疲劳 | 一般 |
| 原生实现成本 | 低 | 低：无阴影、发丝线、少量胶囊 | 低 | 中 |

v0.1 选了 A；用户评审意见：**需要更有个性/品牌感**，并从 B/C/D/A 强化中选择了 **B**。

## 2. 结论（v0.2）：Cursor 暖奶油编辑风为主

**名称：「奶油编辑台」**

- **从 Cursor 取（主体）**：暖奶油底 `#f7f7f4` 而非纯白；暖黑文字 `#26251e` 而非纯黑；唯一品牌电压 **Cursor 橙 `#f54e00`**，节制使用；发丝线分层、无投影；按钮 8px、卡片 12px 圆角；标题字重 400 + 负字距的杂志语气；等宽字体用于数值（JetBrains Mono）；**粉彩胶囊只用于“产品内状态”**（Cursor 的 AI 时间线规则）。
- **从 Cursor 的“featured tier 反色”取**：被选中 = 暖黑底 + 奶油色图标，不再引入第二种强调色。
- **从 Raycast 保留**：keycap 快捷键样式（改为浅色版）。
- **放弃**：v0.1 的深色界面与 lavender 强调色；Cursor 的营销尺寸字号与 80px 区块节奏。

## 3. 本产品特有的决定

1. **橙色只出现在三处**：主按钮“复制”、键盘焦点环、品牌字标。其余所有“当前/选中”状态用暖黑反色表达。
2. **标注色是内容色**：6 色预设饱和、高辨识；红色标注 `#e5342b` 与品牌橙 `#f54e00` 拉开色相，避免混淆。
3. **画布选中框用双色线**（暖黑 1px + 外侧白 1px），保证在任何截图内容上都看得见，不占用品牌橙。
4. **“遮挡”有安全身份**：遮挡工具和遮挡对象使用 Cursor 的深绿 `#1f8a65`（编辑时虚线边框、盾牌角标）；状态栏“已遮挡 N 处”用薄荷粉彩胶囊。这是“粉彩只用于状态”规则在本产品中的落点，也是视觉签名。
5. **状态胶囊家族**：已遮挡（薄荷）、生成中（蜜桃）、已复制 / 已保存（金）、只读或提示（粉蓝）。只出现在状态栏与提示中。
6. **字体**：CursorGothic 为商业授权字体不可用，按其文档采用 **Inter**（拉丁）+ **Noto Sans CJK SC**（中文），数值用 **JetBrains Mono**，三者均为 OFL 开源可打包。
7. **MVP 只做浅色主题**；深色为 P1（PRD 已列入），token 语义命名便于加第二套。

## 5. 框架选定（暂定，待条件验证）

证据：[spike/README.md](../spike/README.md)；独立代理审查：[spike/REVIEW.md](../spike/REVIEW.md)（ACCEPT_WITH_LIMITS，非真人审查）。

**暂定顺序：Slint 1.18.1 首选 → iced 0.14.0 备选 → egui 降级（保留 POC 历史作参考）。**

| 依据（MEASURED / DOCUMENTED） | Slint | iced | egui |
|---|---|---|---|
| 设计稿还原方式 | 声明式 `.slint` + `global` token，最贴近 04_DESIGN | 控件样式闭包，可还原 | 需手工绘制全部界面 |
| 中文/等宽文字垂直居中 | 正确 | 按钮内偏上 | 两种字体偏差明显 |
| 150% 发丝线 | 清晰（取整为 2px） | 最清晰（1px） | 模糊 |
| 空闲私有内存 | 35 MB | 238 MB | 411 MB |
| 无障碍 | AccessKit 默认开启 | 无 AccessKit | 仅真实控件 |
| 许可证 | GPL-3.0 或 Royalty-free 2.0（须 AboutSlint 署名）或商业 | MIT | MIT/Apache-2.0 |

**Slint 转为正式选定前必须取得的证据**（任一 2 或 4 失败 → 对 iced 做同样验证）：
1. **你的许可证决定**：接受 Royalty-free 2.0（在“关于”中显示 AboutSlint）或另选。
2. 24MP `SharedPixelBuffer` 更新延迟与峰值内存，系统 125% / 150% 实测。
3. 选中框拖拽，16×16 手柄命中区。
4. `TextInput` 中文输入法。
5. Narrator 读出工具按钮名称。
6. 修复虚线与工具栏布局后重截对比，并加入 Inter / JetBrains Mono / 粗体（字体下载需你授权）。
7. 无 OpenGL 环境的渲染器回退。
