# 截图诊断包 / Capture diagnostics

用于排查“开始截图时黑屏、闪烁、颜色变化”。在出问题的电脑上运行，结果只是两个文本文件。

## 使用
1. 在托盘图标上右键 → 退出安截。
2. 右键 `anshot-diagnose.ps1` → “使用 PowerShell 运行”。或者在命令行执行：
   ```
   powershell -ExecutionPolicy Bypass -File anshot-diagnose.ps1
   ```
   安截装在别处时，加上 `-Exe <Anshot.exe 的路径>`。
3. 脚本自动截图约 70 次（每次按 Esc 退出），大约 6–7 分钟。期间不要碰鼠标和键盘。如果快捷键没有到达安截（比如 Ctrl+Shift+A 被别的程序占用），脚本在第一轮后就停止，不会继续向其他窗口按键。
4. 脚本提示时，自己从托盘图标截图 5 次，再回答两个问题。
5. 把桌面上 `anshot-diagnose-<时间>` 文件夹里的 `anshot-diag.txt` 和 `rounds.txt` 发给我们。发送前可以先用记事本打开查看。

## 记录与不记录
- **记录：** 每次截图各阶段耗时；屏幕是否变黑（在内存中对缩小的采样计算亮度，不保存画面）；显示器数量、尺寸、缩放、HDR 状态、色深、显卡名称、Windows 版本。
- **不记录：** 屏幕像素、窗口标题、文件路径、识别出的文字。
- 脚本让安截使用临时的设置和历史文件夹，不读取也不改动你自己的设置和截图历史。运行结束后删除临时文件夹，只结束它自己启动的安截。
- 采样本身（约每 2 毫秒读一次屏幕）可能对被测的显示时序有轻微影响，结果以多次统计为准。
- `anshot-diag.txt` 在开关打开期间会一直追加；用完请删掉环境变量。若桌面由 OneDrive 同步，诊断文件夹也会被同步。

## 安截的诊断开关
只有设置了环境变量 `ANSHOT_DIAGNOSE_DIR`（指向一个已存在的文件夹），安截才写 `anshot-diag.txt`。默认不写任何日志。
