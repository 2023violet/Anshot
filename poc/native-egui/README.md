# ShareReady V2-03 Rust Native GUI POC

Isolated Rust experiment, not the shipping V1.3 Windows application.

Native eframe/egui GUI on Windows; Rust Core + Editor processing; rfd dialogs; arboard clipboard. Source PNG/JPEG is decoded by Rust, exported PNG is generated by Rust Core and checked by Editor; GUI overlay is never exported as a screenshot.

Open synthetic T04 image on startup. Draw, move and resize masks, review generated PNG then copy or save as a NEW path. The POC refuses to overwrite existing files.

After the isolated Cargo.lock is committed: cargo build --release --locked --manifest-path poc/native-egui/Cargo.toml. Run its EXE or EXE --self-test (only Core/Editor non-GUI evidence).

The physical Windows GUI acceptance contract is docs/V2/V2_03_NATIVE_GUI_POC.md.
