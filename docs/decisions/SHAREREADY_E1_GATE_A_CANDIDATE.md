# 决策卡：ShareReady E1 最小 Rust/WASM 技术验证（独立工作流）

- 日期：2026-10-15
- 结论：改后做（仅在独立分支及隔离环境完成一次限时、可撤销的安全图像处理与浏览器能力 SPIKE；不得启动正式产品开发）
- 置信度及依据：中；现有两款竞品均可处理真实浏览器内的合成截图，当前 UI 仅为模拟原型；Rust+WASM 的图像安全、浏览器复制与资源边界尚无产品级实测。

## 目标

以最小、可复核的 Rust-first 试验，决定“单页浏览器内处理图片 → 真实不透明遮挡 → 全新 PNG → 复核/复制/下载”是否具有技术可行性，并在无法达到最低安全及平台门槛时明确转向或止损。此目标**不代替 Stage 01 的 A1 真实用户价值验证**。

## 成功标准

1. Rust 内核在合成 T01/T02/T04 上可逐像素覆写全部给定遮挡矩形，未要求改变的保留区域像素一致；包括负向、越界、窄至 1px 的边界用例。
2. 输入 JPEG T05 及仿真 EXIF/GPS/Orientation 后能输出**重新编码、无源 EXIF/GPS 与无源图层**的新 PNG，并能独立复查输出尺寸与解码后的最终像素；损坏/超大输入能失败封闭。
3. Rust/WASM 的独立浏览器演示仅接收本地合成图片，在至少一次真实 Chromium 环境中完成输入→遮挡→生成 PNG→下载→从实际 PNG bytes 复核，不使用 CSS 覆盖冒充像素处理。
4. 对浏览器真实 Clipboard API 写入 PNG 的成功、拒绝/不支持与下载替代提供可重复、区分“已验证/环境阻断”的证据；不把 UI 点击计为复制成功。
5. 有编译/测试日志、依赖许可与网络审计、最小性能/峰值内存数据、原始测试产物、跨平台限制及独立审查记录，形成 GO / NEEDS_REWORK / SWITCH_HOST / NO_GO 的技术建议，不宣称 A1 商业价值通过。

## 非目标

- 不修改或关闭原 Stage 01 的 Gate A/B 与真实 S05a BLOCKED_BY_RECRUITMENT，不把真人样本数 0 改为通过。
- 不开发完整的 ShareReady 业务产品、正式账户/云端服务、OCR/AI/批量/PDF/视频/发布管线。
- 不写入 main，不合并 PR，不部署、发布、打 tag 或创建 Release，不向第三方上传任何用户私人图片。
- 不从本次 Gate A 预览直接实施 Rust 代码；Gate A 明确确认、Gate B 执行命令与副作用预览确认、额外工程授权均未发生前不得编码。
- 不把技术测试通过表述为匿名化绝对安全、产品可发布或已经获得用户需求证据。

## 关键假设

| # | 假设 | 若不成立的后果 | 状态 |
|---|---|---|---|
| A1 | Rust 核心可正确、可测试地重新编码不保留源元数据的遮挡 PNG | 停止 Web-first 工程，不允许用 CSS/模糊作为替代安全路径 | 未验证 |
| A2 | 浏览器 Rust/WASM 输入、内存与导出可在实际桌面环境稳定运行 | 评估 Tauri 2 作为替代 host，另行审批，不暗中扩大范围 | 未验证 |
| A3 | Clipboard 在目标浏览器权限和用户手势下可用，失败可明确退回下载 | Clipboard 保持条件特性，不阻断安全下载路径 | 未验证 |
| A4 | 已认可的 UI 能对接真正输出复核状态，不暴露旧成品 | 不推进 UI 全功能接线，先重构状态与输出契约 | 未验证 |

> 本卡的 A1 是“E1 技术内核可行性”，**不是**原 Stage 01 的“真实用户需求 A1”；两个决策相互独立。

## 止损条件

- 触发状态：最小验证在源像素覆盖、全新 PNG 与私密离线输入方面无法通过，或为通过测试必须新增未经授权的云端依赖/大规模产品代码。
- 期限：2026-10-31
- 动作：立即停止 E1 实验，保留独立分支的失败证据与 NO_GO/SWITCH_HOST 建议；如需改变架构或权限范围重新提案审批。

## 升级阈值

- 修复失败次数上限：2

## 最大风险

将外观良好的 UI 或自动化生成的 PNG 误认为真正安全处理，忽略格式元数据、像素边缘、浏览器 Clipboard 权限与大图片内存边界，从而先实施大量不可靠的业务代码。
