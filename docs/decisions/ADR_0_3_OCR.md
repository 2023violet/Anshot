# ADR 0.3-OCR：用 Windows 自带的文字识别（本机、离线）

日期 2026-10-24 · 状态：用户已批准（0.3.0 计划，2026-10-24）

## 背景
竞品调研（`reports/截图标注工具竞品对比.md`）显示离线 OCR 是中文用户更换截图工具的主要原因之一，Windows 截图工具已内置。0.1 / 0.2 的 PRD 把 OCR 列为非目标。

## 决定
- 只调用系统组件 Windows.Media.Ocr（`windows` crate =0.62.2，特性 Media_Ocr 等），不打包模型、不下载、不联网。
- 输入是 Rust 生成的像素：选区为冻结帧的裁剪；编辑器与钉图为 `anshot-render` 渲染出的导出图（遮挡已生效，被遮的内容识别不到）。像素以 BGRA 拷贝交给系统，系统不解码任何文件。
- 小区域先在 Rust 中放大 1.5 倍再识别（可行性验证：100% 缩放下中文 92% → 99%）。
- 结果只显示在可编辑窗口（不写历史、不落盘），该窗口设为不被截图（WDA_EXCLUDEFROMCAPTURE）；用户复制为纯文本。
- 识别语言：优先中文（简体），否则用户配置的语言；没有可用语言时提示用户在 Windows 设置里添加，不自动安装。

## 证据（MEASURED，见 `spike/ocr/RESULT.md`）
- 未打包的 exe 可以创建引擎；本机只有 zh-Hans-CN。
- 合成中文 96.44%（×1）/ 99.70%（×1.5）；600×400 冷启动 78 ms。
- e2e 第 32 部分：选区识别 92.4%，编辑器识别 88.1%，打码的手机号未被识别出来。

## 局限（NOT_VERIFIED）
Windows 11、仅装英文的系统、ClearType 子像素文字、深色主题、首次开机后的耗时、多显示器 / DPI。识别结果可能有错字，界面上如实提示。
