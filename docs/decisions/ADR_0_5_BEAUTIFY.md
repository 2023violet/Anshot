# ADR 0.5-BEAUTIFY：成品美化（Rust 合成、不透明、不改截图像素）

日期 2026-11-02 · 状态：用户已批准（0.5.0 计划，2026-11-02）

## 背景
0.4 让“输出可信”变得看得见。用户希望产品更有新意；分享出去的截图常常还要拿到别的工具里加背景、圆角，再发到聊天、文档或社交平台。Xnapper、CleanShot 有这类“美化”，国内截图工具少见（推断，未做系统调研）。

## 决定
- **范围：** 背景（纯色、两色渐变、自动取色）、留白、圆角、阴影；出图比例 1:1 / 4:3 / 16:9 / 3:4 / 9:16，截图居中、不裁切；窗口外框（macOS 三圆点、Windows 标题栏、浏览器地址栏）。
- **合成位置：** 全部在 `anshot-render`。`render_into` 不变，`render_png` 在裁剪之后加一步 `render_framed`；`Scene.frame` 为 `None` 时输出逐字节不变，五张 V1 金样本和 scene-v1 ~ v4 不受影响。渐变用 tiny-skia 自带着色器，阴影用手写的降采样盒式模糊，不加依赖。
- **不改截图：** 成品里截图区域的像素与不带美化的导出逐像素相同，只有圆角切掉的四角不同。遮挡、标注、裁剪的结果不变。
- **不透明：** 背景铺满整张图，alpha 恒为 255。透明背景不做，因为很多程序把透明像素显示成黑色。
- **文档属性，不进撤销：** 美化设置跟着当前文档，改动会让已准备的导出作废，但不压入撤销栈；关掉开关即恢复。
- **预览：** 打开面板时画布显示 Rust 渲染的带框成品，暂停标注；关掉面板回到编辑。画布坐标和点击换算不变。
- **尺寸上限：** 成品不超过 `MAX_PIXELS`（2400 万像素）。放不下时先缩小留白，仍放不下就提示并关闭美化。
- **隐私：** 外框文字只由用户输入，程序不自动填入窗口标题或网址；文字只在内存和交付出去的成品图片里，不写进设置和日志（历史保存的是成品图片，所以含有这段文字的像素）。自动取色只用已遮挡、已裁剪的渲染结果。
- **检查：** 手动检查、识别文字、钉图用不带框的画面；交付后的自动检查和出图自检按截图在成品中的位置换算坐标，外框和背景里的结果丢弃。

## 局限（NOT_VERIFIED）
- 各聊天软件、社交平台对成品的二次压缩和显示效果没有测过。
- 外框是简化的示意图样，不追求和真实系统一模一样。
- 真人审美评价、Windows 11、多显示器、系统缩放、HDR 未验证。
