## 一、产品定义

**目标：** 一张已存在的截图，在发送前由用户明确框选需要隐藏的区域，确认实际重编码的成品图，然后复制 PNG 或下载 PNG。桌面浏览器优先，完全单任务工作台，不需要登录、历史项目或云存储。

**核心流程：** 图片导入 → 遮挡与调整 → 成品复核 → 复制/下载。正式名称暂用内部代号 ShareReady，法律品牌清查尚未通过。

**竞争现实：** Redacted、Redaction Tools 已在真实 Chrome 合成 T01/T02 测试中完成该任务。因此免费、纯本地、手动框选、复核、PNG 导出都**不是独占卖点**。唯一优先探索的体验方向是减少编辑认知负担、区分已生成成品与编辑遮罩；是否真有增益仍须验证。

## 三、输入输出安全合同

1. 单文件、静态 PNG/JPEG。不能用文件扩展名作为唯一格式判断。SVG、PDF、GIF 多帧、视频与远端 URL 不在 V1 中。
2. 候选输入上限：单文件 25 MiB，解码图像 24 MP。这两个数字仅为设计估值，**未通过 Rust/WASM 内存测量**，技术实验后才冻结。
3. EXIF orientation 归一后建立**原始解码图像像素坐标系**；显示缩放不是图片输出像素缩放。
4. 矩形原图像素区间采用半开边界，左/上向下取整、右/下向上取整，再钳位至图像宽高。允许 1px 窄框；负方向拖动先归一化。
5. 遮挡填充候选值 #111827，不透明 alpha=255，必须替换最终输出缓冲中的真实像素；半透明叠加、模糊或像素化不满足敏感信息覆盖保证。
6. 输出必须由新编码 PNG 构成，不复用 JPEG/PNG 原 buffer、附加源图层或隐私元数据；当输出安全路径失败时**拒绝导出**，绝不能退回导出原图。
7. 用户每次修改遮挡都会使旧输出 bytes 失效；复核和复制必须引用当前版本同一个输出工件。
8. 复制需要真正成功才展示成功状态；浏览器拒绝复制不得误报，下载 PNG 为回退。
9. 网络威胁：输出图和源图不得上传到服务器；在真正完成源码/Network/CSP 审计之前，不宣称已经通过“离线隐私安全”测试。
10. 产品不能自动发现未框选的敏感信息，也不能承诺受监管场景合规或匿名身份不可推断。

## 四、可实现的状态机与不可跳过的检查

| 状态 | 画面/动作 | 不变量 |
|---|---|---|
| EMPTY | 导入拖放区与选择按钮 | 无文件不得进入复核 |
| DECODING | 限制大小/读取/解码 | 失败不假装读取成功 |
| EDITING | 画布、遮挡工具、区域列表、撤销/重做 | 任何编辑动作立即废弃旧输出 |
| RENDERING | 生成新 PNG bytes；锁定复制下载 | 编码失败要阻断输出 |
| OUTPUT_REVIEW | 单独显示从新成品 bytes 解码的最终图、供人自查 | 不无意暴露原图并排对照 |
| EXPORTED | 成功下载/真实复制反馈 | 可回编辑，但重编辑必须重新生成 |
| RECOVERABLE_ERROR | 精确错误原因及返回/下载替代 | 保留有效图片和编辑记录 |

版本一致性：output_valid 只在“编辑版本与成品对应、编码成功、必要自检完成”时成立。返回编辑再动遮挡框后，不能复制旧版本。

## 六、待正式确认的产品决策

- D1：V1 首发聚焦**普通桌面分享前隐私遮挡**，不是监管类合规材料处理。
