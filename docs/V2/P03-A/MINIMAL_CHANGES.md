# P03 A 最小修改清单

以下均为候选，尚未修改任何产品代码。按当前缺口安排，不创建正式 apps/desktop，不新增业务框架，不升级 GUI 库，也不重写已有 Core/Editor。每项实施时先固定反例或验收步骤，再限定 diff、运行相应回归，证据绑定修改后的版本。

## M01 可核对的测试证据

只为合成测试会话记录实际图框、pixels_per_point、指针按下/移动/释放、推导区域、实际 mask、DocumentId/Revision/OperationId 和结果。默认正式运行不记录图片内容、文件名、路径或输入事件。没有明确测试模式和数据边界时，不添加全局调试日志。

原生导出检查工具应读取已有输入 PNG、记录的区域和保存的 PNG，独立比较全帧 RGBA、尺寸、PNG chunks/CRC/元数据/尾部。它不启动现有 Rust CLI，避免继承 Linux 路径前置条件。JPEG 继续使用已冻结的 Rust 归一化锚点，不改预期哈希。M01 完成只证明取证能力，需要用错误区域或带尾部的测试输出验证它确实会拒绝错误。

## M02 先固定语义再实现

建议 D02：100% 为一来源像素对应一屏幕物理像素，Fit 按当前可视区域计算；200% 为每来源像素对应 2×2 物理像素。GUI 布局仍使用逻辑点。搬屏或 DPI 变化重算图框，保留来源遮挡；不能仅给滑块改标签。

Fit 可使用缩略图；100%/200% 的可见成品区域必须来自真实 PNG 原分辨率像素。先按 GPU 限额选择最小可行纹理/可视区方案，不立即建设通用分块缓存。验证 T04 与 24MP，记录资源，若现有简单方案够用则停止扩展。

## M03 复用已有编辑命令

用 Editor 的 add_mask/move_mask/resize_mask/select/history/gesture 方法完成键盘路径。允许用小型像素区域输入或明确的初始矩形创建方式满足精确任务；选择后可以按 1px 步进。Esc 调用取消而不是提交，拖拽一次只入一条历史。文本控件聚焦时不抢夺删除、撤销、粘贴或输入法。

手柄可见性和命中反馈只做到八向操作可辨，不进行整体界面重设计。当前领域已有无翻转、1px、边界与历史规则，只有测试发现确实缺失时才改领域层。

## M04 与 M05 统一输入和保留编辑

图片粘贴以系统真实图像格式为输入，明确不支持格式的反馈；文本输入焦点时保留标准粘贴。PNG/JPEG 文件先受限读取再解码；剪贴板图像按像素数和资源预算限制，不能先构造无界大 PNG 再查输入上限。

候选图通过解码和显示准备后，用户确认放弃旧编辑才替换。文件、拖放、粘贴共用策略，取消/拒绝/解码失败保留原源图、区域和历史。多文件拖入建议在读取前拒绝并说明单图范围，由 D05 确认。关闭时同样给出放弃或返回；清空可采用可撤销方式，不能静默改变既有产品约定。

## M06 限定保存与复制

建议 D03：POC 与首个正式版本均仅另存新文件，拒绝覆盖。原合同的 overwrite 测试仍执行，预期是明确拒绝且原文件哈希不变；该预期变更需单独接受，不把拒绝覆盖冒称支持覆盖。

采用不会覆盖用户文件的完整写入策略，覆盖同名竞争、短写、磁盘满、同步失败和重试；清理仅针对本次创建且身份确认的产物。失败不可显示成功，不能顺手删除用户目录或既有目标。故障测试通过适配层注入，不填满宿主磁盘或改系统 ACL。

复制图像与保存 PNG 分别命名；跨应用验证图像尺寸、RGBA 与 alpha。若 Windows 目标格式不能保持 alpha，记录限制并重审 D04；不能自动将“不支持透明度”改成验收通过。外部剪贴板已写入的旧图不可撤回，状态必须如实描述。

## M07 与 M08 取得真实平台证据

先为必要中文标签与文件名解决字体覆盖，核对字体文件来源、授权和离线可用性。Narrator 至少读出选区身份、尺寸、工具、焦点、错误和交付结果。无需为测试 IME 增加没有产品用途的文本框；原生文件名输入与 egui 标签分别验证。

CI 必须显式报告所需 wgpu/DX12 结果；glow 可作为兼容观察，不能让 glow 单独成功抵消所需主路径失败。对独立 POC 的 0 项测试保留真实数量，同时保证主 Workspace 领域回归实际执行。不得新增写权限或自动提交锁文件。

## M09 仅针对观测到的问题扩展并发

先补全新绘制、已有手势、换图、撤销和交付失败的状态测试；复用现有令牌，不另建一套版本号。系统操作同步时，通过可控延迟返回的适配层验证旧结果，再分别观察 GUI 实际可操作性。

只有真实测量显示 UI 长时间阻塞，才将受限读取或 PNG 工作移出 UI 线程。结果必须携带原操作身份，取消可以先使令牌失效，不要求复杂异步框架。线程相关改动另列命令和风险，不能作为本次首批默认范围。

## 修改验收的共同约束

每项最多安排一个工作时段的实施子步，超过 8 小时就拆分。关键 P0 一轮有界修复后仍失败，返回方向评审，不连续引入第二第三种技术路线。任何源像素泄露、过期成品成功、静默丢编辑或覆盖源图的反例，立即阻断该批交付。

不得通过修改五张冻结期望、缩小 G06/G08 范围、跳过多屏或删除失败测试达成通过。修改清单不是实施授权，Gate B 应只选择当批必要项。
