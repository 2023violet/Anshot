## 已完成的产品修改

- 增加 Fit、100%、200% 入口。100% 按一源像素对应一屏幕物理像素换算，DPI 改变时重新计算逻辑图框。Fit 使用有界缩略图；100%/200% 使用实际 PNG 的可见原始像素、NEAREST 采样和不超过设备限额的纹理分块。
- 修复 Ctrl+Z/Y 读取帧末修饰键导致快捷键漏判的问题，按按键事件自己的修饰键处理；实际 Windows `ctrl + command` 组合有回归用例。文本编辑获得焦点时，画布不抢 Delete、Undo 和输入。
- 增加键盘 N 创建居中遮挡、选中后方向键按 1 源像素移动、对应可聚焦按钮、八向可见手柄、Esc 取消手势及返回编辑入口。已有八向 1px 调整按钮继续复用 Editor。返回编辑本身保留已生成 PNG，下一次真实编辑或绘制预览使其失效。
- 新绘制保留最初按下位置；跨过拖动阈值不会移动起点。新框预览立即撤销旧 PNG 及待交付凭证，取消不增加历史，完整拖动只产生一条撤销记录。编辑后状态文字不再残留旧的“PNG 已显示”提示。
- 新增独立 PNG 文件检查器，使用 Pillow 构造全图 RGBA 期望，检查不透明替换、遮挡外像素、尺寸、RGBA8 格式、PNG CRC、元数据、尾部和 IDAT 压缩流残留。该工具不调用 Rust 导出器作为独立真值。JPEG 仍需冻结的 Rust 归一化 PNG 锚点，不能随意改期望值。
- `--synthetic-trace <目录>` 明确启用合成取证：绑定内置 T04，禁用私人图片导入，记录实际图框、ppp、原始 Pointer 事件、源坐标、区域、版本和 Review 操作身份，并写出合成 PNG 与区域 sidecar。普通启动不创建追踪文件。输出文件使用 `create_new`，不覆盖已有材料。
