## 本轮允许的操作

Gate B 确认后，从已核验的本地 CI 工件启动 EXE（参数 `--renderer wgpu`）。这是交互窗口，会持续到操作者关闭；不重新编译 POC。先做第 1 项最小观察，再做其他检查；已明确缺入口的场景停止尝试，记录缺口。

1. **最小 H01 观察**：用内置 T04，在当前屏绘制一个框、查看成品、返回并撤销；将窗口移动至第二屏，观察画布与指针是否发生可见偏移、裁切或失焦。记录当前缩放值、现象和窗口截图（只含合成图）。正常现象只能记 OBSERVED，不能证明像素精度。
2. **G01/G03**：在两屏分别观察 100% 和 200% 当前滑条行为、滚动与窗口尺寸变化。当前显示语义、Fit、独立指针轨迹及原像素复核存在缺口，必须分项记录；不得凭“看起来正常”填写精确像素 PASS。
3. **G02**：画框后尝试已有移动/八方向命中、Delete、撤销/重做和 Esc；注明哪些有可见提示、哪些没有入口。不要把仅 Z/Y/Delete 可用写成完整键盘闭环。
4. **G08**：先保存操作者当前 Narrator 开关状态；使用系统 Narrator 开关（Win+Ctrl+Enter）尝试 Tab 焦点、按钮名称和遮挡区域语义，记录实际朗读及无法到达的控件。结束后恢复原开关状态；不安装辅助工具、不改系统权限。
5. **G01～G10 汇总**：逐项对照 P03 A GAP_MATRIX 与 TEST_CASES，区分实际观察、已知实现缺口和未执行。图片粘贴、剪贴板格式、跨应用粘贴、保存失败注入、DPI 设置变更及新增特殊样本均不在本轮操作范围，不得据此给这些用例 PASS。

本轮不操作剪贴板，不保存/覆盖图片，不写源图、不安装依赖或改系统设置；截图与文字证据只写 Gate B 绑定的 `target/p03-b-evidence/b0-20261017/` 下新建的操作者子目录。系统 Narrator 状态的临时切换和恢复是本轮唯一显式系统开关操作。结束后关闭本次测试窗口；不要终止其他同名进程。

## 每条记录格式

| 字段 | 必填内容 |

| case_id / G 编号 | 对应原协议用例；基线探索另标 B0-OBS，不冒充完整用例 |
| 状态 | OBSERVED / FAIL / NOT_RUN / NOT_VERIFIED / IMPLEMENTATION_GAP |

| 限制与复验 | 缺少入口、独立 oracle、设备或自动化时写明下一步 |
