## 下一批最小修改建议（尚未实施）

1. **M01 先建立可信取证**：只在明确的合成测试模式下记录图框、指针、比例与版本；增加读取文件的独立 PNG oracle，并用错误矩形、元数据和尾部载荷反例验证拒绝能力。默认运行不收集图片、路径或输入事件。
2. **M02 补齐像素视口**：先确认 D02 的物理像素 100%/200% 语义，再接 Fit、跨屏比例重算与真实 PNG 原像素复核。复用领域 Viewport；不默认引入复杂分块或异步框架。
3. **M03 与必要 M07 补齐任务入口**：接可见八手柄、精确区域、键盘创建/选择/1px 移动、Esc 取消、文本焦点保护和有授权的中文字体；Narrator 语义必须随后实测。

该顺序对应 G01/G02/G03/G08 和 H01；M04～M06 仍是完整产品必需项，不从后续范围删除。新产品代码、D02～D05 产品合同和具体执行命令需要进入下一批评审，本轮 B0 不实施这些修改。

## 自动控制证据与当前限制

用户明确授权 Codex 直接控制本机调试，随后通过 computer-use 的 @oai/sky 对真实原生窗口执行操作。操作者为 CODEX_COMPUTER_USE_AUTOMATION，不是人工使用性测试。原始无障碍状态与实际动作时序见 [B0_AUTOMATION_OBSERVATIONS.json](B0_AUTOMATION_OBSERVATIONS.json)。

实际完成并核对十项有限断言：Tab 到达 Open image 和 Review；键盘激活 Review 后出现成品标签且 Copy/Save 可用；键盘激活 Undo 后版本递增、矩形改变、Copy/Save 禁用；Redo 后原有五个矩形恢复、版本再次递增且 Copy/Save 仍禁用。初始 Revision 6，撤销后 7，重做后 8；五个框是接管窗口时已有的合成编辑状态，不声称由本次自动指针创建。

发现两个具体问题：注入 Control_L+z 后没有可观察变化，根因尚未区分工具/应用；Undo/Redo 后状态文字仍保留“Rust encoded PNG shown. Inspect all unmasked details before copying.”，但交付按钮实际已禁用。后者是陈旧状态提示，不能据此声称旧成品实际可交付。当前缺少单独返回编辑入口；不将 Undo 当作最终返回设计。

截图多次返回 FrameArrived/window capture timeout，坐标点击返回 coordinate input geometry is unavailable。已按技能恢复流程重新绑定、通过系统菜单最大化再还原，捕获仍失败；停止使用截图坐标，没有伪造画布截图。只读打开 Windows 设置也遇到 SystemSettings.exe 的系统错误，本次提示已关闭，未修改显示或系统设置。截图、鼠标像素、每屏 DPI、跨屏精度与 Narrator 音频仍 NOT_VERIFIED/NOT_RUN。

测试结束时通过 Redo 恢复接管时的五个矩形，通过系统菜单恢复正常窗口。没有操作剪贴板、保存图片、改 DPI、修复系统或安装驱动。形式上的“观察步骤完成”仅指基线证据与缺口记录齐备，不代表缺失场景通过。原合同范围、五张样本、33 项人工协议用例保留。
