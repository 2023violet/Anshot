# Five synthetic redaction benchmarking inputs — S02

All files generated by `generate.py` contain **fictional** names, domains, telephone numbers, image labels and metadata. Never substitute screenshots provided by real research participants into the public repository.

## Task mapping

| ID | Material | Required masking | Preserved content |
|---|---|---|---|
| T01 | Demo group-chat screenshot | fictional avatar, sender name, demo phone, notification | conversation content |
| T02 | Demo order screenshot | fictional recipient, phone and address | item, amount and item problem |

The machine-readable `manifest.json` records original pixel coordinates, PNG/JPEG dimensions, file SHA256, target mask rectangles and areas that must stay visible. Expected output for the later product is a newly re-encoded PNG, opaque replacement at marked pixel coordinates and no original image metadata. **This is test ground truth, not evidence of a working product.**

Generate with `python3 -m pip install Pillow==12.3.0` then `python3 docs/research/fixtures/generate.py`. The exact software environment and version should be recorded if regenerating. `T05_JPEG_EXIF.jpg` intentionally contains **fabricated** EXIF and GPS for detecting unsafe exports.

Current scope is visual and metadata fixtures, not a claim about recognition/AI accuracy. Record visual QA separately; automatic region assertions alone do not establish visual realism, usability or privacy security.
