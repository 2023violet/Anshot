# ShareReady V1｜UX/UI 设计基线候选 v0.1

**2026-10-15 · DESIGN REVIEW ONLY · NO RUST APPLICATION CODE**

以 [功能合同候选](../product/SHAREREADY_V1_FUNCTION_CONTRACT_CANDIDATE.md) 为输入。A1/A2 仍未验证，既有 Gate B 状态未改。本基线是供用户审查的 UI/UX 方向，不是交付完成的真实产品。

## 一、设计主张

“打开—处理一张截图—确认成品—分享”。保持**单工作区、不需要学习图像编辑器**。界面优先图像，而不是宣传图或长段说明。已有竞品具备复核、无账号、本地处理等功能，不能把这些声明为独占创新。

- 工作台首屏出现导入入口；编辑时以画布为中心。
- 安全关键操作区分：编辑中看到的是工作预览，**检查成品时才显示真正输出数据**。
- 状态文案只描述已执行动作，不写“已自动检测所有隐私”。
- 工具数量尽量少：遮挡、选择、平移、缩放、撤销、重做、检查成品。
- 视觉语言偏工程师工具：浅色中性表面、低对比背景、强调色只用于选中与主操作，保持中文自然表达。

## 三、信息架构与布局

**不设二级页面导航。** 候选桌面画板 1440×900。

- 顶部 60px：临时代号 ShareReady / 当前图片名称 / 撤销重做 / 主操作「检查成品」。
- 左侧 62px：绘制遮挡（默认）、选择调整、手形平移；底部显示缩放工具。
- 中央弹性画布：棋盘中性背景 + 图像展示；图片内部坐标与 CSS 屏幕位置隔离。
- 右侧 300px Inspector：图片格式与原始像素尺寸、当前遮挡数、编号区域列表、选中区域操作和简短提示；不展示从图片 OCR 得到的任何私人文字。
- 底部 48px：状态、缩放比例、基础快捷键提示。
- 顶部设置按钮仅打开小型 Popover，不设多层 Settings 页面。

## 五、操作与文案契约

- 没有图片：主按钮不可用，提示「先导入图片」。
- 新增遮挡：区域列表出现「区域 01」，选区状态与画布同步。
- 新编辑使旧成品过期：提示「已修改，请重新检查成品」。
- 成品复核：展示**最终输出**；提示「已遮挡 N 处。分享前请核对边缘、通知、头像与未遮挡内容。」不出现“安全评分”。
- 复制成功：只能在浏览器真正写入后显示；拒绝则说「复制未获允许，可下载 PNG」。
- 导出失败：保持编辑内容，绝不能回退导出原图。
- 更换当前图：明确提示所有遮挡会被清空；不能暗中丢弃。
- 粘贴：聚焦非文本区时处理图片，文本输入框内不能抢夺默认 Ctrl+V。
- 快捷键：R 遮挡、V 选择、H 平移、Ctrl/Cmd+Z 撤销、Shift+Ctrl/Cmd+Z 重做、Delete 删除选择、0 适合画布、Esc 取消/关闭；需要避免与系统组合键冲突。

## 六、可实现状态与过渡

EMPTY → DECODING → EDITING → RENDERING → OUTPUT_REVIEW → EXPORTED。ERROR 为可恢复子状态。每次重新编辑都撤销上次成品有效性。

**设计原型注意：** HTML 演示文件使用内置虚构截图，不允许导入真实文件、不调用真实复制/下载，不进行像素安全处理。即便 UI 能模拟编辑/复核，也不得宣称它可保护私人图片或已实现 Rust 引擎。

## 七、尺寸和无障碍

- 1440×900：完整四区布局。
- 1024–1199：Inspector 变窄，较长解释折叠，画布保有主空间。
- 小于 960：Inspector 作为切换面板/折叠，明显说明桌面浏览器优先；不承诺移动端 P0。
- 色彩与 focus：主要控件可 Tab、Enter；错误不仅靠颜色，提供明确语句；选中矩形有描边和拖动句柄。
- 任何视觉比例都不能替代源图片像素坐标，尤其是高 DPI 边缘。
